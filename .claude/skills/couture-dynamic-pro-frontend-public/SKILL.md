# Phase 5 — Frontend public

Construire mobile-first : accueil, catalogue, fiche produit, liste et détail catalogue, flipbook placeholder contractuel, panier, checkout, compte, blog, contact/devis et chat placeholder. Utiliser la charte, SSR/Metadata API pour SEO/OG, états loading/error/empty, accessibilité et partage.

Critères : responsive 1/2/3 colonnes, pages catalogue indexables, formulaires validés, aucun prix de confiance côté client, parcours navigation-panier stable, PageSpeed cible ≥ 85.

Prompt de session : « Implémente l'écran [nom] pour [acteur]. Utilise les données d'API existantes, cite les RG, couvre les états d'interface et ajoute le test utilisateur ciblé. »
