# Phase 6 — Dashboards

Construire le back-office ADMIN et CONTENT_MANAGER : KPI ventes, commandes, vues catalogues, PDF, flipbook, partages, produits, commandes, CRM minimal, contenus et planification. Respecter le périmètre de chaque rôle et RG2/RG10.

Critères : données filtrées côté serveur, actions d'archivage explicites, historique visible, états vides et erreurs, aucune donnée personnelle inutile dans les statistiques.

Prompt de session : « Implémente le module back-office [module] pour le rôle [rôle]. Vérifie les permissions, les métriques et les états d'erreur ; ajoute un test d'accès refusé. »
